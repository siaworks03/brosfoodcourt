Drop your menu files in this folder (PNG, JPG, WEBP or PDF), then list them in index.html
on the Menu card, in data-menu-files. Example:
  data-menu-files="Broasted|assets/menu/broasted.png,Mandi|assets/menu/mandi.png,Full menu|assets/menu/menu.pdf"
Format: Label|path, comma separated. Label is optional.
